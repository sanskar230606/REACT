# React Course Projects

This repository contains React projects created while learning React.js and frontend development using Vite.

The projects cover core React concepts such as components, props, state management, event handling, styling, hooks, Tailwind CSS, and form handling.

## Topics Covered

### Functions and Components
Understanding functional components, reusable UI structure, and component-based development in React.

### Props
Learning how data is passed between components and how reusable components are created using props.

### CSS Styling
Working with CSS inside React applications, including layout design and component styling.

### Tailwind CSS
Building responsive interfaces using utility-first styling with Tailwind CSS.

### Webpage Layouts
Creating multi-section webpage structures using reusable React components.

### useState Hook
Managing dynamic data and updating the UI using React state.

### Advanced useState
Handling arrays, objects, and more complex state updates in React applications.

### Form Handling
Managing form inputs, controlled components, form submission, and event handling using `preventDefault()`.

### Event Handling
Working with functions, user interactions, and browser events inside React components.

## Technologies Used

- React.js
- Vite
- JavaScript
- JSX
- CSS
- Tailwind CSS
